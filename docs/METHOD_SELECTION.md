## 📊 方法对比表

| 特性 | IVD | TC | EIVD | ETCC | Bayesian TC |
|------|-----|----|----- |------|-------------|
| **产品数量** | 2 | 3 | 3 | 3 | 3+ |
| **假设误差独立** | ✓ | ✓ | 允许相关 | ✓ | ✓ |
| **时变误差** | ✗ | ✗ | ✗ | ✗ | ✓ |
| **优化目标** | 融合 | 最小化误差方差 | 最小化误差方差 | 最大化相关性 | 贝叶斯后验 |
| **计算复杂度** | 低 | 低 | 中 | 中-高 | 高 |
| **适用场景** | 主被动融合 | 通用 | 相似传感器 | 降水等应用 | 复杂误差结构 |
| **输出不确定性** | ✗ | ✗ | ✗ | ✗ | ✓ (MCMC) |

## 🔍 方法详解

### 1. IVD (Information Vector Dual) - 两产品配准

**适用场景**：
- 只有两个独立产品（如主动和被动遥感）
- 需要估计误差和融合权重

**核心假设**：
- 两产品测量同一真值
- 误差相互独立
- 误差零均值

**优点**：
- 计算简单快速
- 直接提供融合权重

**缺点**：
- 只能处理两个产品
- 无法处理误差相关

```python
from collocation import ivd
EeeT, rho2, u = ivd(dual_data)  # dual_data: (n, 2)
```

---

### 2. TC (Triple Collocation) - 经典三重配准

**适用场景**：
- 有三个独立产品
- 产品来自不同传感器/算法（误差独立）
- 需要估计每个产品的误差方差

**核心假设**：
- 三产品测量同一真值
- 误差相互独立（零交叉相关）
- 误差零均值

**优点**：
- 最广泛使用的方法
- 理论成熟，解释性强
- 计算效率高

**缺点**：
- 严格要求误差独立
- 无法处理时变误差

```python
from collocation import tc
EeeT, SNR, rho2, fMSE = tc(tri_data)  # tri_data: (n, 3)
```

---

### 3. EIVD (Extended Information Vector Dual) - 扩展配准

**适用场景**：
- 三个产品，但其中两个可能有误差相关
- 产品来自相似传感器（如同一家卫星的不同通道）

**核心假设**：
- 三产品测量同一真值
- 允许产品2和产品3之间存在误差相关
- 产品1与其他产品误差独立

**优点**：
- 可处理部分误差相关
- 更符合实际情况

**缺点**：
- 计算稍复杂
- 只允许一对产品误差相关

```python
from collocation import eivd
EeeT, SNR, rho2, fMSE, L = eivd(tri_data)  # tri_data: (n, 3)
# 注意：EeeT[1,2] 包含误差交叉相关
```

---

### 4. ETCC (Extended TC for Correlation) - 相关性优化

**适用场景**：
- 目标是最大化融合产品与真值的相关性
- 降水产品融合（相关性比误差方差更重要）
- 需要通过穷举搜索找到最优权重

**核心假设**：
- 三产品测量同一真值
- 误差相互独立

**优点**：
- 专门优化相关性
- 适合降水等非高斯数据
- 输出融合产品与真值的估计相关

**缺点**：
- 穷举搜索计算量大
- 不直接最小化误差

```python
from collocation import ETCC
etcc = ETCC(weight_increment=0.01)
merged = etcc.merge(x, y, z)
print(etcc.weights)  # 最优权重
print(etcc.max_correlation)  # 与真值的相关
```

---

### 5. Bayesian TC - 贝叶斯三重配准

**适用场景**：
- 误差可能随时间变化
- 需要完整的不确定性量化
- 有足够计算资源运行 MCMC

**核心假设**：
- 误差结构可以随时间变化
- 使用先验信息
- 通过 MCMC 采样得到后验

**优点**：
- 提供完整的不确定性估计（置信区间）
- 可处理复杂误差结构
- 输出时变的误差估计

**缺点**：
- 需要 PyMC3，计算量大
- 需要设置先验
- 收敛可能需要调参

```python
from collocation import BayesianTC, BAYESIAN_AVAILABLE
if BAYESIAN_AVAILABLE:
    btc = BayesianTC(data)
    btc.run_inference(niter=2000)
    rmse_mean, rmse_std, rmse_ci = btc.get_error_estimates()
```

## ✅ 理论假设检查表 (Assumption Checklist)

在使用任何配准方法前，请检查以下假设是否满足：

### 通用假设（所有方法）

| 假设 | 描述 | 如何检验 |
|------|------|----------|
| 📏 **同一真值** | 所有产品测量同一物理量 | 确认产品观测的是同一变量（如土壤湿度、降水） |
| 🎯 **误差零均值** | 误差平均为零（无系统偏差） | 检查产品均值是否相近，或预先去偏 |
| 📈 **足够样本量** | 有足够数据估计统计量 | 建议 N ≥ 100（TC 建议 N ≥ 200） |
| 🔢 **数值稳定** | 数据不含 NaN/Inf | 预处理时检查并移除 |

### 方法特定假设

| 方法 | 特定假设 | 违反时的后果 |
|------|----------|-------------|
| **IVD** | 两产品来自不同传感器原理 | 如果相似，误差可能相关，估计有偏 |
| **TC** | 三产品误差完全独立 | 估计的误差方差会有偏（通常低估） |
| **EIVD** | 只有一对产品误差相关 | 如果多对相关，估计不准 |
| **ETCC** | 误差独立 | 融合权重可能次优 |
| **Bayesian TC** | 先验设置合理 | 后验可能被先验主导 |

### 快速检查流程

```
□ 1. 数据预处理
   □ 移除 NaN/Inf
   □ 检查时间序列长度 ≥ 100
   □ 确保产品时空配准

□ 2. 偏差检查
   □ 计算每个产品的均值
   □ 如有显著偏差，考虑预先去偏
   □ 或使用带 rescaling 的 TC

□ 3. 独立性检查（如使用 TC）
   □ 确认产品来自不同传感器/算法
   □ 如有两个相似产品，考虑使用 EIVD

□ 4. 结果验证
   □ 检查估计的误差方差是否为正
   □ 检查 SNR 和 ρ² 是否在合理范围
   □ 与已知验证数据对比（如有）
```

## 🎓 使用建议

### 新手入门推荐

1. **从 TC 开始**：最经典、最稳定的方法
2. **数据充足时**：使用 N ≥ 200 的时间序列
3. **预处理**：移除异常值，确保数据质量

### 进阶应用

1. **检测误差相关**：先用 TC，再用 EIVD 比较
2. **降水产品**：考虑 ETCC 优化相关性
3. **复杂场景**：Bayesian TC 提供不确定性

### 常见问题

**Q: 估计的误差方差出现负值？**
- 可能违反了误差独立假设
- 尝试使用 EIVD 或预先去偏

**Q: 样本量多少才够？**
- TC: 建议 N ≥ 100，最好 ≥ 200
- Bayesian TC: N ≥ 500 效果更好

**Q: 如何选择参考产品？**
- TC 和 EIVD 结果不依赖参考选择
- 但 rescaling 时应选择最可靠的产品
