
# A Bayesian Three-Cornered Hat (BTCH) Method: Improving the Terrestrial Evapotranspiration Estimation

> He, X., Xu, T., Xia, Y., Bateni, S.M., Guo, Z., Liu, S., Mao, K., Zhang, Y., Feng, H., Zhao, J. (2020). *Remote Sensing* 12(5):878.  
> This repository implements a faithful, practical replication of the BTCH workflow with **runnable demo code** using synthetic data.

---

## 论文信息 (Paper Information)
- **期刊 (Journal):** Remote Sensing, 2020  
- **DOI:** 10.3390/rs12050878  
- **一句话总结 (Summary):** 在无需 a priori 观测的情况下，使用 **Bayesian-based Three-Cornered Hat (BTCH)** 融合多源 ET 产品，得到更准确、稳定的陆面蒸散发估计。  
  In the absence of in-situ priors, **BTCH** fuses multiple ET products to yield more accurate, stable terrestrial ET estimates.

- **关键词 (Keywords):** Evapotranspiration, BTCH, TCH, Bayesian fusion, Uncertainty

---

## 复现说明 (Replication Note)
本代码库旨在（最大程度地）复现论文中的 **BTCH 融合** 与 **不确定性估计** 的核心思想与工作流；并提供一个可运行的**合成数据**示例，演示如何计算 TCH 协方差、推导 BTCH 权重并进行加权融合。  
This repo aims to replicate the core BTCH fusion and uncertainty estimation workflow with a runnable **synthetic-data** demo showing how to compute TCH covariance, derive BTCH weights, and perform fused ET estimation.

- **复现状态 (Status):** 已完成可运行示例（核心算法 + 可视化 + 评估）。  
  Completed runnable example (core algorithm + viz + evaluation).
- **已知差异 (Known Deviations):** 为实用可运行，本文提供了两种 TCH 实现：
  1) **经典无相关 TCH（Classic, uncorrelated）**：假设误差互不相关，基于差分方差的最小二乘求解各产品误差方差；
  2) **相关型 TCH 的正则近似（Correlated, regularized approx.）**：通过最小化 \(\|J R J^T - S\|_F^2 + \alpha\|\text{offdiag}(R)\|_F^2\) 并投影到 PSD，近似论文中给出的 Kuhn–Tucker 约束解。  
  To be practical and runnable here, we include: (i) a classic uncorrelated TCH (LS on diff-variance), and (ii) a **regularized correlated** TCH (minimize \(\|J R J^T - S\|_F^2 + \alpha\|\text{offdiag}(R)\|_F^2\) with PSD projection) as a tractable approximation of the Kuhn–Tucker constrained solution described in the paper.

## 分析工作流 (Analysis Workflow)
1. **数据预处理 Data Preprocessing** — 生成或加载多源 ET 产品时间序列（示例采用合成数据）。  
   Script: `src/01_data_preprocessing.py` → output to `data/processed/`
2. **BTCH/TCH 估计 BTCH/TCH Estimation** — 计算差分协方差 \(S\)、求解 \(R\)、得到误差方差 \(\sigma_i^2\) 与 **BTCH 权重**；并与 **EM**（Ensemble Mean）对比。  
   Script: `src/03_analysis_workflow.py`
3. **可视化与评估 Visualization & Evaluation** — 绘制时间序列、散点评估图（R, RMSE, Bias）。  
   Script: `src/04_visualization.py` → `results/figures/`

## 如何运行 (How to Run)

## ⏱️ 时变权重（Time-Window BTCH）
新增脚本：
- `src/02_windowed_btch.py`：按 **月 / 季 / 半年** 三种窗口计算 **时变 BTCH 权重**（相关/无相关两种模式），并输出评估指标与每个分组的权重与方差。
- `src/05_visualization_windowed.py`：生成对应的时间序列对比图。

实现思路：以日期分组（例如按月 M01..M12），在每个分组内对合成/真实产品子集估计 TCH→BTCH 权重，并将该组权重应用到对应时间索引，得到时变融合序列。

## 🗺️ 空间维度示例（Spatial Example）
新增脚本：
- `src/11_generate_spatial_demo.py`：生成 (T,Y,X) 网格真值与 N 个ET产品（含产品间相关误差）。
- `src/12_btch_spatial_example.py`：像素级计算 **静态 BTCH 权重** 和 **月度时变权重**（均基于无相关 TCH，示例轻量易跑），输出 EM 与 BTCH 的 RMSE 地图与汇总指标。

> 实际应用时，可在 `src/loaders.py` 中实现 `load_real_products_grid()` 接口，读取你自己的网格化产品（如 GeoTIFF/NetCDF），并替换演示数据。

## 🔌 真实数据接口（Real Data Interfaces）
- `src/loaders.py` 提供了 `load_real_products_timeseries()` 和 `load_real_products_grid()` 的**函数签名与说明**，只需在 `data/raw/` 放入你的真实产品并实现读取逻辑，即可把本仓库的时变 BTCH / 空间示例直接用于真实数据。
